# system/wallpanel-gamma/

`wallpanel-gamma`: our own small Wayland client for night shift. It takes the wlr-gamma-control of the
kiosk output once and sets every colour temperature it reads from stdin **without releasing the
control** – no neutral flash between two temperatures (restarting `wlsunset` for each new value
releases the control, cage falls back to the identity ramp for a moment). Needs our cage
([`../cage/`](../cage/), applies gamma ramps to the VOP LUT).

| File | Content |
|---|---|
| `wallpanel-gamma.c` | the program; colour math copied unchanged from wlsunset 0.4.0 (MIT, notice in the file) |
| `meson.build` | build; version = `pkgver`; protocol code generated by `wayland-scanner` from Alpine's `wlr-protocols` (`wlr-gamma-control-unstable-v1.xml`) |
| `APKBUILD` | Alpine package, `makedepends="meson wayland-dev wlr-protocols"`, runtime: `wayland-libs-client` |

## Interface

```
wallpanel-gamma [-o NAME] [-f MS] [-v]      # also -V (version), -h (help)
```
- Environment: the compositor's `XDG_RUNTIME_DIR` + `WAYLAND_DISPLAY` (kiosk: `/run/wallpanel`,
  `wayland-0`), run as user `wallpanel`.
- `-o NAME`: only this output (`wl_output` v4 name, kiosk `DSI-1`); default all outputs present at start.
- `-f MS`: fade to each new value over MS ms in integer-Kelvin steps every 20 ms (default 0 = jump).
  A new value during a fade fades on from the current step.
- stdin: one integer Kelvin value per line, 1000–25000 (`\n`, surrounding blanks/`\r` ignored), optionally
  followed by a red and a blue gain in % (50–100, e.g. `3300 92 96`): the white is scaled per channel below
  4000 K, fading out towards 6500 K (neutral stays the identity ramp); a changed gain is applied at once.
  A fourth value sets the fade of this change in ms (e.g. `3300 92 96 0`: at once), otherwise `-f`.
  Applied on receipt; several lines arriving together: only the last one counts. Empty lines are
  ignored, invalid ones are logged and ignored (the program keeps running). 6500 = identity ramp
  (control still held, so the VOP LUT stays enabled with an identity table).
- Colour: wlsunset's `calc_whitepoint(K)` + ramp fill with gamma 1.0 – bit-identical tables to
  wlsunset for the same K (checked for 1000–25000 K, ramp sizes 256/1024/4096, on the device).
  Note: `wlsunset -t K -T K+1` shows K+1 by day, so the old behaviour differed by 1 K.
- Nothing is set before the first line (the compositor shows identity).
- stderr log: `wallpanel-gamma: DSI-1: gamma control acquired, ramp size 1024` once started,
  then one line per accepted value (`3000 K`, or `3000 K (fading from 6500 K over 2000 ms)`);
  `-v` adds every applied step. stdout stays empty.
- Exit: **0** on stdin EOF (control destroyed → compositor restores identity); **1** with
  `wallpanel-gamma: error: …` if there is no compositor, no gamma manager, the output is missing
  or removed, the ramp size is 0, the control fails (e.g. another client – `wlsunset`, a second
  instance – holds it, both at start and later) or the connection is lost; **2** for bad options.
  SIGTERM: the compositor releases the control when the client dies (identity).

Intended use (`apps/wallpanel-api`): start once per compositor session, keep its stdin as a pipe,
write `"K R B\n"` for every new temperature or colour balance, restart it when it exits, close stdin to stop.

## Build, install, pin

- `./build.sh wallpanel-gamma [--install]` (`tools/build-wallpanel-gamma.sh`, same flow as
  `tools/build-cage.sh`): refreshes the `sha512sums` in `APKBUILD` from the sources, builds natively
  with `abuild` on the device over `tools/tssh` (build deps in the virtual package
  `.wallpanel-gamma-build`, removed afterwards with the build directory), signs with the local key
  `tools/apk-key/`, copies the apk to `build/out/wallpanel-gamma-<pkgver>-r<pkgrel>.apk`.
  Timestamps: last commit of this directory (or the files' mtime while uncommitted) → the same sources
  give a byte-identical apk.
- `--install` / `tools/install.sh`: `apk add` of that file, then `/etc/apk/world` gets
  `wallpanel-gamma=<version>` (the package is in no repository; `apk fix` cannot re-fetch it –
  reinstall with `./build.sh wallpanel-gamma --install`).

Rules:
- Our own source: changes directly in `wallpanel-gamma.c`/`meson.build`, no patch series, no pin file.
- Every change of the program: bump the version in `meson.build` **and** `pkgver` in `APKBUILD`
  (the build script refuses a mismatch), `pkgrel=0`. Packaging-only change: bump `pkgrel`.
- Keep the colour math identical to wlsunset (the api's temperatures were tuned with it).
- Check on the device: `apk info -e -v wallpanel-gamma`; `printf '3000\n' | wallpanel-gamma -o DSI-1`
  as `wallpanel` logs `3000 K`; while it runs a second instance exits 1 ("gamma control failed").
